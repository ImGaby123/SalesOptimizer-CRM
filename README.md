# 📊 CRM and Sales Optimizer Project (University Project)

A **Customer Relationship Management (CRM) system** with a built-in **Sales Optimizer** and **Admin Dashboard**, developed as part of a university group project. The system was designed to reflect real-world development workflows and simulate business processes.

---

## 👥 About the Project

This project was collaboratively developed by a team of university classmates as part of a systems analysis and design course. It emphasized realistic development practices, including requirements analysis, architectural planning, backend logic, and team coordination.

---

## 🧰 Tech Stack

- **Languages:** Python, SQL  
- **Frameworks/Libraries:** PySide6, PyQt, Matplotlib  
- **Architecture:** MV (Model–View)  
- **Database:** MySQL  
- **Tools:** PowerPoint, Visual Studio, Qt Creator

---

## 📂 Project Highlights

- 🧩 Built core CRM features for managing leads and clients  
- 📊 Modeled sales pipeline and processes using custom business logic  
- 🎯 Developed lead scoring and Ideal Customer Profile (ICP) features  
- 🔐 Implemented role-based access and admin management tools
